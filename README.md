Ciel is a set of skills that aims to be the core of a framework combining
AI speed with a human-in-the-loop approach — focused on keeping **me** in
the loop.

## Motivation

I've tried to find solutions that would let me stay on top of a project
while using AI to handle the boring stuff. But AI tends to either do things
wrong, or do too much. Ciel is my attempt at generic agent skills/prompts
that produce results I can actually review and use. PRs are welcome :)

## Scope

This is not intended to be used as-is. It's meant to be built around, and modified. Ciel is not aiming to become a 500+ skill project.
