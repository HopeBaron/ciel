# Enforcement

Read this only when the baseline showed an agent knowing a rule and skipping it anyway.

**The dose is blast radius times observed defection rate.** Not genre, not house style. Default
is zero devices. Each device below must name the transcript line that earned it.

An unearned absolute is worse than none: it trains the reader to skim your emphasis.

## The kit, in order

**1. Spirit/letter clause, in the first fifteen lines.** Closes an entire class of
rationalisation before the agent reaches for it.

> **Violating the letter of this process is violating the spirit of <X>.**

**2. Iron Law.** One fenced, all-caps, unqualified sentence, followed immediately by its concrete
consequence — not a restatement.

```
NO PRODUCTION CODE WITHOUT A FAILING TEST FIRST
```
> Write code before the test? Delete it. Start over.

**3. The no-exceptions loophole list.** Enumerate the specific workarounds, ending in a tautology
that refuses reinterpretation: "Not for simple additions. Not for just adding a section. Don't
keep it as reference. **Delete means delete.**"

**4. Rationalisation table.** `| Excuse | Reality |`, excuses quoted **verbatim from the
baseline**. The Reality column rebuts on the excuse's own terms — answer "no time" with "this is
faster", not with "quality matters". Close with `**All of these mean: <single required action>.**`

**5. Red flags, as inner monologue.** "If you catch yourself thinking: 'Quick fix for now,
investigate later'..." terminated by `**ALL of these mean: STOP. Return to <phase>.**` The
mechanism is recognition: the agent meets its own next sentence in a list of prohibited moves.

**6. Partner signals.** Externalise the red flags to the human's words. "Stop guessing" means you
are proposing fixes without understanding. Converts user frustration into a trigger.

**7. Iteration caps that escalate to a category change**, not a retry limit: "If three fixes have
failed, stop and question the architecture. This is not a failed hypothesis, it is a wrong
architecture."

## Lighter devices, any genre

| Device | Shape | Use when |
|---|---|---|
| `**Done when:**` | checkable + exhaustive clause per step | any procedure |
| Gate function | `BEFORE <action>: <checklist>`, placed immediately before the action | a just-in-time precondition beats an up-front checklist |
| Hard-gate tag | a visually distinct wrapper, unlike the rest of the structure | the one rule that must survive skimming |
| Do-not-proceed | "Do not proceed until you have reproduced **and** minimised." | a phase boundary with real cost to crossing early |
| Ranked options with a named floor | 1-10, with "10. Last resort." | stop the agent reaching for the expensive option first |
| Literal string mandate | hand over the exact string, not the policy | compliance text the model would paraphrase away |
| Falsifiability template | "If X is the cause, changing Y makes it disappear." | force testable claims |

## Persuasion doses

| Genre | Use | Avoid |
|---|---|---|
| Discipline | Authority + Commitment + Social proof | Liking, Reciprocity |
| Procedure, Orchestration, Dialogue | Moderate Authority + Unity | Liking, Reciprocity |
| Vocabulary, Router | Clarity only | All persuasion |

Never use Liking for compliance: it produces sycophancy and conflicts with honest feedback.
The test for any of it: would this technique serve the user's genuine interests if they fully
understood it?
